# ha-enbrighten-vibe

A Home Assistant integration for Enbrighten VIBE permanent outdoor lights.

## Project Status

🚧 Reverse engineering in progress.

Current goals:

- Decode the Tuya protocol used by Enbrighten VIBE lights.
- Provide complete local LAN control.
- Publish as a HACS integration.
- Support advanced features such as effects, speed, zones, and per-light masking.
